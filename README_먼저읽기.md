# AI Vision 2~5차시 · Netlify 단독 통합 웹사이트

## 1. 무엇을 만들었나요?

**하나의 Netlify 웹주소**에서 왼쪽 메뉴 또는 홈 카드로 **2차시 → 3차시 → 4차시 → 5차시**를 자유롭게 이동합니다. 별도 Streamlit 서버, Python 설치, Colab 계정 없이 교육용 실습 기능이 웹브라우저에서 동작하도록 구성했습니다.

| 차시 | 실제 웹에서 동작하는 기능 | 원본 파일과의 관계 |
|---|---|---|
| **2차시** | 제공된 정상·불량 예시 선택, 사용자 이미지 업로드, 실제 픽셀 기반 이상점수 계산, OK/REVIEW/NG 판정, Original/Heatmap/Overlay/Contour, JSON 결과 저장, 5차시 기록 추가 | **원본 EfficientAD 추론이 아님.** 교육용 PixelAD-v2 기준선 모델입니다. |
| **3차시** | 제공된 **v7 HTML 원본 시뮬레이터** 전체 실행. 촬영조건·ROI·조명·STL/GLB·Before/After·실험 로그·데이터 Export. 현재 정상 캡처 이미지를 4차시로 전달 | 원본 HTML의 계산·시뮬레이션 방식을 보존했고, 부모 페이지 통합 캡처 API만 추가했습니다. |
| **4차시** | 정상 이미지 16장(대표 GOOD 이미지의 촬영조건 증강) 기본 제공, 정상 이미지 추가, **실제 브라우저 픽셀 평균/표준편차 학습**, REVIEW/NG 임계값 조절, 모델 JSON 내보내기/가져오기, 대표 GOOD/BAD 평가 | 원본 4차시 Colab 노트북이 제공되지 않았습니다. EfficientAD 학습이 아닌 교육용 PixelAD-v2 학습입니다. |
| **5차시** | 같은 PixelAD 모델로 예시 검사 1건/9건 일괄 실행, OK/REVIEW/NG 건수, 판정 분포, 검사 기록, CSV 내보내기, 로컬 기록 보관. 첨부 EfficientAD 최종 테스트 지표 별도 표시 | 원본 Streamlit의 운영 흐름을 **브라우저 실습용으로 재구현**한 것. 산업 현장 PF1 추론과 판정은 실행하지 않습니다. |

### 매우 중요한 사실

원본 2차시 파일의 `model/model.ckpt`는 약 72MiB이고 Python/Anomalib/PyTorch/EfficientAD 엔진이 필요합니다. **이를 Netlify 정적 배포만으로 그대로 추론 및 재학습하는 것은 이 파일 구성으로 불가능합니다.** 실제 EfficientAD가 실행된 것처럼 가짜 점수나 오버레이를 표시하지 않았습니다. 이 배포본에서 사용한 **PixelAD-v2는 완전히 다른 모델**입니다. 두 모델의 점수·임계값·성능은 서로 직접 비교할 수 없습니다.

- 원본 EfficientAD 판정 기준 `review_low = 0.21444829232516993`, `ng_high = 0.5438568345905579`은 **참고 정보**로만 5차시에 표시합니다.
- 2·4·5차시의 PixelAD 점수는 0~100의 별도 척도로 **실제 영상차이를 계산**한 결과입니다. 결함이 아닌 조명/자세 변화에도 반응할 수 있습니다.
- 초기 샘플은 2차시 패키지에 포함된 대표 정상/불량 이미지 **각 1장**과 그 이미지의 밝기·대비 변형본입니다. 독립 검증 데이터셋이나 실제 현장 촬영 이미지라고 표현해서는 안 됩니다.
- 원본 EfficientAD의 학습·검사 재현이 반드시 필요하다면 **별도 Python 실행 서버 또는 검증된 ONNX/WebGPU 변환 모델**이 필요합니다. 현재 첨부 원본은 브라우저용 ONNX 형식이 아닙니다.
- 기업에서 받은 이미지와 코드는 공개 배포 허락 여부를 확인하세요. **원본 약 72MiB 체크포인트는 이 ZIP에 넣지 않았습니다.**

## 2. 새로운 GitHub 계정에 올리기

1. ZIP 압축을 풉니다.
2. GitHub에서 새로운 저장소(예: `ai-vision-learning-lab`)를 만듭니다.
3. ZIP 폴더 **내부의 `site/`, `netlify.toml`, `README_먼저읽기.md` 등 전체 파일을 저장소 최상위**에 업로드합니다. GitHub Desktop을 권장합니다.
4. 구조가 다음과 같으면 됩니다:

```
ai-vision-learning-lab/
├─ netlify.toml       # Netlify가 site/를 배포하도록 설정
├─ site/
│  ├─ index.html      # 2, 3, 4, 5차시가 포함된 단일 사이트
│  ├─ netlify.toml
│  ├─ assets/
│  │  ├─ app.css
│  │  ├─ engine.js     # 실제 교육용 이상탐지 계산
│  │  └─ app.js        # 차시 이동 / 파일 / 로그 / 관제
│  ├─ simulator/
│  │  └─ index.html   # 3차시 v7 원본 + 부모 연동
│  └─ data/           # 대표 이미지 / 학습용 증강 예시 / 원본 참고 지표
├─ tools/             # 테스트/QR 생성 보조 도구
└─ README_먼저읽기.md
```

## 3. Netlify에서 GitHub 연동 배포

1. <https://app.netlify.com/> 접속 → **Add new project** → **Import an existing project**.
2. GitHub 연결 → 새 저장소 선택.
3. **Base directory**: 빈칸. **Build command**: 빈칸. **Publish directory**: `site`.
4. **Deploy** 클릭. `netlify.toml`에도 동일한 배포 폴더가 지정되어 있습니다.
5. 배포 후 `https://내-사이트.netlify.app` 주소로 접속하여 왼쪽 2·3·4·5차시 버튼을 점검합니다.

> 참고: **Netlify Drop**으로만 업로드할 경우, 저장소 루트가 아니라 압축을 푼 **`site` 폴더 자체**를 드래그하면 됩니다. GitHub 연동을 원하면 최상위 폴더 전체를 저장소에 업로드하세요.

## 4. 보고서 QR 주소

Netlify 주소가 `https://my-lab.netlify.app`인 경우:

```
전체 홈   https://my-lab.netlify.app/#home
2차시     https://my-lab.netlify.app/#02
3차시     https://my-lab.netlify.app/#03
4차시     https://my-lab.netlify.app/#04
5차시     https://my-lab.netlify.app/#05
```

해시(`#02` 등)는 **하나의 사이트 안에서 차시를 전환하는 주소**입니다. `tools/create_qr.py`를 사용하면 QR 5개를 PNG로 만들 수 있습니다 (`pip install qrcode[pil]`).

## 5. 학생에게 안내할 실제 동작 순서

1. **2차시**: GOOD / BAD 샘플을 각각 선택한 후 검사 버튼으로 점수·근거 그림을 비교합니다. 이미지를 직접 올릴 수도 있습니다.
2. **3차시**: Baseline을 저장하고 조명 1개만 변경한 뒤 Before/After를 비교합니다. 원본 시뮬레이터 ZIP/실험기록 기능도 사용 가능합니다. 정상 이미지를 4차시로 보내는 연결 버튼이 있습니다.
3. **4차시**: 제공된 정상 이미지 학습을 다시 실행하거나 3차시 생성/사용자 GOOD 이미지를 추가해 재학습합니다. 임계값을 바꾸어 판정 결과가 왜 달라지는지 평가합니다.
4. **5차시**: 다음 부품 검사 또는 9개 예시 일괄 검사를 실행하여 그래프·이력·CSV를 확인합니다.

> 정상 데이터만을 학습시킨다고 해서 새 이미지의 결함 여부가 반드시 정확하게 판단되지는 않습니다. 기준 부품의 모양, 촬영조건, 배경, ROI를 일관되게 맞추는 것이 중요합니다. 3차시에서 만든 *기어/브라켓* 이미지를 자동차 부품 GOOD 학습에 섞으면 오히려 모델 기준이 흐려질 수 있습니다. 이 차이를 탐구하도록 구성했습니다.

## 6. 사용 데이터 / 개인정보

- 사용자의 업로드 이미지는 **브라우저 내부에서만 처리**하며 서버로 전송하지 않습니다.
- 검사 이력과 학습모델은 해당 브라우저의 `localStorage`에 보관합니다. 브라우저 초기화 또는 시크릿 모드 종료 시 사라질 수 있습니다.
- 3차시에서 4차시로 전달한 이미지와 직접 추가한 학습 이미지는 **현재 탭 세션에서만 유지**됩니다. 새로고침하면 추가 이미지가 초기화되지만, 이전에 학습하여 저장한 모델 파라미터는 브라우저에 남을 수 있습니다.
- Netlify에는 **사용자별 서버 데이터베이스 / 원본 EfficientAD 모델 추론 서버가 없습니다**.
- 외부 사용 시 웹페이지 안에 들어 있는 대표 이미지와 지표가 공개된다는 점에 유의해 공개 권한을 확인하세요.

## 7. 검증

- `site/assets/engine.js`, `site/assets/app.js`: Node.js 문법 검사 완료.
- Chromium 자동화 테스트: 기본 PixelAD 학습(16장), 2차시 GOOD/BAD 검사, 4차시 대표 이미지 평가, 5차시 9장 일괄검사 성공. JavaScript 콘솔 예외 0건.
- 3차시: 원본 HTML 코드 및 추가 브리지 정적 검사 완료. 원본 시뮬레이터의 모든 개별 입력 조합을 전수 테스트한 것은 아닙니다.
- **Netlify 실서버 배포는 계정 접속 및 배포가 없으므로 아직 검사하지 못했습니다.** GitHub와 Netlify에 업로드한 뒤 URL에서 최종 확인하세요.
