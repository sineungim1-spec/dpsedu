AI Vision Dashboard - 4차시 Candidate4 2Epoch Bundle 호환 수정

수정 원인
- 교육용 Candidate4 2Epoch bundle에는 model_info.json / config.json이 없고,
  image_size=256이 artifacts/preprocess_profile_v6.json에 저장되어 있었습니다.
- 기존 범용 Dashboard는 config.json 또는 model_info.json에서만 image_size를 찾아
  bundle 검증 단계에서 중단되었습니다.

수정 내용
1. EDUCATION_SUMMARY.json에서 model / epochs 자동 인식
2. preprocess_profile_v6.json 또는 operating_window.json에서 image_size 자동 인식
3. protocol_v6.json에서 TRAIN/CALIBRATION/FINAL counts와 seed 자동 인식
4. Candidate4/PF1 decision_model + localization + preprocess artifact가 있으면
   기존 PF1 Decision Score/ROI/4-view runtime을 그대로 사용
5. threshold.json의 review_low/ng_high를 재계산하지 않고 그대로 사용
6. Final Test가 없는 교육용 bundle은 Calibration metrics를 Dashboard 성능정보로 표시
7. deployment_validation.json이 EDUCATION_ONLY이면 경고만 표시하고 추론은 허용
8. 기존 Legacy 2-ZONE / 일반 3-ZONE / RAW score bundle 로직은 유지

검증
- 첨부 Candidate4_E07S_2Epoch_Dashboard_Bundle 로더 검증 PASS
- model=EfficientAD-S
- image_size=256
- score_mode=PF1_DECISION
- review_low=0.3989133783576479
- ng_high=0.3989133783576479
- Calibration AUROC=0.875 표시 확인
- 기존 2-ZONE / 일반 3-ZONE 계약 회귀검사 PASS
- 전체 Python 문법검사 PASS

주의
- 이 bundle은 deployment_validation 기준 EDUCATION_ONLY_TEST_NOT_RUN입니다.
- Dashboard는 이를 Production Ready로 표시하지 않습니다.
- review_low와 ng_high가 동일하므로 현재 이 bundle의 REVIEW 구간 폭은 0입니다.
