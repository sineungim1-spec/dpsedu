# 5차시 Streamlit 원본 실행 및 배포

제공된 `AI_Vision_dashboard.zip`에서 소스코드를 복사했습니다(컴파일 캐시 `.pyc`, `__pycache__` 제외).

## 로컬 실행

```sh
cd code/05_streamlit
python -m venv .venv
# 설치된 Python 버전에 맞게 가상환경 활성화
pip install -r requirements.txt
python -m streamlit run app.py
```

대용량 torch/anomalib 설치 환경과 하드웨어 여건에 따라 실행되지 않을 수 있으므로 로컬에서 원본대로 확인하세요. 이 통합 배포본에서는 클라우드 추론 테스트를 완료했다고 주장하지 않습니다.

## 별도 서비스 연동

- 공개 GitHub 저장소를 Streamlit Community Cloud에 연결할 경우 앱 경로: `code/05_streamlit/app.py`
- 의존성: `code/05_streamlit/requirements.txt`
- 실제 실행 가능성을 확인한 다음 나온 `https://...streamlit.app` URL을 `site/site-config.json`의 `streamlit_url`에 기록합니다.
- 사용자 업로드 파일과 모델의 배포·공개 권한 및 서버 메모리 제한을 확인하세요.

Netlify는 이 Python 앱을 직접 실행하지 않습니다. `site/05/`는 안전한 정적 자료 열람 페이지입니다.
