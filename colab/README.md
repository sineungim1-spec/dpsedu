# 4차시 Google Colab 연동

현재 첨부파일에 실제 4차시 `.ipynb` 노트북이 없어서 **원본 학습 노트북을 포함하지 않았습니다.**

1. 실제 수업에 사용한 노트북(`.ipynb`)을 이 폴더에 복사합니다.
2. GitHub에 업로드한 후 해당 노트북을 Colab에서 열어, 공유 가능한 URL을 확인합니다.
3. `site/site-config.json`에서 `colab_url`에 URL을 넣고 커밋/푸시합니다.
4. `https://배포주소/04/`에서 버튼이 열리는지 확인합니다.

`04_COLAB_연결용_안내.ipynb`는 이 단계들을 설명하는 **안내용 노트북이며 모델 학습 코드가 아닙니다.** 실제 수업 산출물로 인용하지 마세요.
